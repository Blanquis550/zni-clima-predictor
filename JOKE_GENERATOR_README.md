# 😄 Random Joke Generator API\n\nAplicación Streamlit que genera chistes aleatorios usando la API externa JokeAPI.\n\n## Características\n\n✨ Generador de chistes aleatorios\n🎯 Múltiples categorías de chistes\n⚡ Interfaz interactiva en Streamlit\n🔄 Actualización en tiempo real\n💾 Historial de chistes\n\n## Instalación\n\n```bash\npip install -r requirements.txt\nstreamlit run joke_generator.py\n```\n\n## Uso\n\n1. Abre la aplicación: `http://localhost:8501`\n2. Selecciona una categoría de chistes\n3. Haz clic en \"Generar Chiste\"\n4. ¡Disfruta!\n\n## API Utilizada\n\n[JokeAPI](https://jokeapi.dev/) - API gratuita de chistes en múltiples idiomas\n
